Claude deployments use subscription-level quota pools. This reference explains how quota is shared, how cached
tokens are counted, and which default limits apply to each Azure subscription type.

## Quota scope

- Global Standard deployments of the same model and version share one quota pool across all regions in a subscription.
- Data Zone Standard deployments of the same model and version share one quota pool within each data zone.

For general quota management guidance, see [Quotas and limits](/setup/quotas-limits).

## Rate-limit measurements

Claude models use three measurements:

| Measurement | Meaning |
| --- | --- |
| Requests per minute (RPM) | Number of requests accepted per minute |
| Uncached input tokens per minute (ITPM) | Input tokens that aren't read from a prompt cache |
| Output tokens per minute (OTPM) | Tokens generated by the model |

For most Claude models, ITPM includes uncached input after the last cache breakpoint and tokens written to either the
5-minute or 1-hour prompt cache. Tokens read from the cache and output tokens don't count toward ITPM.

<Tip>
Total input tokens include uncached input, cache-creation input, and cache-read input. Only the first two categories
count toward ITPM.
</Tip>

For details about cache accounting, see
[Rate limits in the Claude API documentation](https://platform.claude.com/docs/en/api/rate-limits#rate-limits).

## Default limits

**Yes** means the model and deployment combination supports quota allocation, although its default numeric limit can
be zero. **N/A** means that combination isn't supported.

## Check or increase quota

The **Quota** page in the Foundry portal shows the quota available to your subscription. To request more quota, submit
the [quota increase request form](https://aka.ms/oai/stuquotarequest). Requests are evaluated individually and aren't
guaranteed to be approved.

When the API returns HTTP 429, use exponential backoff and reduce request frequency or token usage. For deployment and
invocation errors, see [Troubleshoot Claude model deployments](/models/capabilities/use-foundry-models-claude#troubleshooting).
