Claude model quotas and rate limits determine how much traffic each model can process in Microsoft Foundry. This reference explains quota sharing, prompt-cache accounting, and the default limits for each Azure subscription type.

## Understand quota scope

Microsoft Foundry manages Claude model quota at the subscription level:

- Global Standard deployments of the same model and version share one quota pool across all regions in a subscription.
- Data Zone Standard deployments of the same model and version share one quota pool within each data zone, such as the US data zone.

For general quota management guidance, see [Microsoft Foundry Models quotas and limits](/foundry-models/quotas-limits).

## Understand rate-limit measurements

Claude models use three rate-limit measurements:

- **Requests per minute (RPM)** counts requests.
- **Uncached input tokens per minute (ITPM)** counts input tokens that aren't read from a prompt cache.
- **Output tokens per minute (OTPM)** counts generated tokens.

### Account for prompt caching

For most Claude models, ITPM includes:

- Input tokens after the last cache breakpoint
- Tokens written to either the 5-minute or 1-hour prompt cache

<Tip>
Total input tokens include uncached input, cache creation input, and cache read input. Cache read input and output tokens don't count toward ITPM.
</Tip>

For details, see [Rate limits in the Claude API documentation](https://platform.claude.com/docs/en/api/rate-limits#rate-limits).

## Check or increase quota

The **Quota** page in the Foundry portal shows the quota available to your subscription. To request capacity beyond the default limits, submit the [quota increase request form](https://aka.ms/oai/stuquotarequest). Approval isn't guaranteed.

## Handle rate-limit errors

When an application exceeds a rate limit, the API returns HTTP 429. Implement exponential backoff, reduce request frequency or token usage, and request more quota when the defaults don't meet your workload requirements.

For deployment and inference errors, see [Troubleshoot Claude model deployments](/models/capabilities/use-foundry-models-claude#troubleshooting).
