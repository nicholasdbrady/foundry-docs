Microsoft Foundry Notification Center centralizes important observability alerts and notifications for your agents, models, and projects. It aggregates critical signals into a single in-app feed so you can identify and address problems directly in the Foundry portal without configuring multiple monitoring systems.

## When to use the Notification Center

Use the Notification Center when you want a single in-portal feed for critical Foundry signals. For example:

- Catch high-severity Microsoft Defender for Cloud security alerts on your agents or infrastructure.
- Track Azure Policy or guardrail compliance issues across your projects.
- Know when long-running evaluation or training jobs finish or fail.

## Prerequisites

- An active Microsoft Foundry project. To create one, see [Create a project](/setup/create-projects).
- Access to the [Foundry portal](https://ai.azure.com).

## Delivery channels

The Foundry web portal currently delivers notifications in-app. A badge on the bell icon indicates new unread items.

## Key capabilities and alert coverage

### Centralized notifications panel

Select the bell icon in the Foundry portal header to open the Notification Center panel. The panel shows recent read and unread notifications with timestamps and short descriptions. Select an item to view details or navigate to the relevant resource. Select **Dismiss all** to mark all notifications as read.

### View all notifications page

The expanded view lists all notifications, including older and previously read items. Use this page to review, filter, and audit notifications by criteria such as type, project, or severity.

### Alert types covered

The Notification Center aggregates these categories of events:

- **Security alerts**: High-severity security issues from Microsoft Defender for Cloud, including malicious activity or content safety violations.
- **Policy and compliance**: Issues from Azure Policy or Foundry guardrails, such as governance policy violations or required compliance actions.
- **Run completion and other events**: Completion or failure notifications for long-running operations such as evaluation runs or model training jobs.

## Use the Notification Center

<Note>

These steps require portal access. For role requirements, see [Role-based access control for Microsoft Foundry](/security/rbac-foundry).

</Note>

### Access notifications

In the Foundry portal, select the Notification Center bell icon. The panel displays recent notifications with a description and an icon or color indicating the category or importance. Unread notifications are highlighted.

### View notification details

Select a notification to open its details or the relevant page:

- For agent evaluation alerts or run completions, the notification can open the **Operate** page or evaluation results for the related agent or run.
- For security or policy alerts, the notification can open the relevant Azure portal security or policy compliance page.

### Mark notifications as read

The panel marks an alert as read after you review it. Select **Dismiss all** to mark all current notifications as read.
